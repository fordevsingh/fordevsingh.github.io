# Devashish Singh | Personal Profile Website

A responsive personal profile and portfolio website built with plain **HTML and CSS** and hosted on **GitHub Pages**.

**Live site:** https://fordevsingh.github.io/

## Sections
- **Hero:** photo, name, and short introduction
- **About Me:** background and what I enjoy building
- **Education:** B.Tech at Manipal Institute of Technology and earlier schooling
- **Projects:** HoopDB, Hotel Management System, and OpenBook, each linked to its GitHub repo
- **Skills:** languages, frameworks, databases, and developer tools
- **Interests:** sports and analytics, building projects, and learning
- **Contact:** email and GitHub

## Project structure
```
.
├── index.html     # page structure and content
├── style.css      # colours, fonts, layout, and responsive rules
├── images/
│   └── profile.jpg
└── README.md
```

## Design notes
- Fonts: DM Sans and Manrope (Google Fonts)
- Layout: CSS Grid and Flexbox, with breakpoints at 850px and 640px for tablets and phones
- Sticky navigation bar with smooth scrolling to each section
- Hover effects on buttons and cards

## Run locally
Open `index.html` in any modern browser. No build step or dependencies are needed.

## Deploy with GitHub Pages
1. Create a **public** repository named `fordevsingh.github.io`.
2. Upload `index.html`, `style.css`, `README.md`, and the `images` folder to the repository root.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then click **Save**.
4. After about a minute, the site is live at `https://fordevsingh.github.io/`.
